# Phantom Engine

High-performance voxel engine for Minecraft 26.3 written in pure Rust (wgpu/Vulkan + Rayon) with a standalone native launcher.

### [Download Windows Release (.ZIP)](https://github.com/yaroxe/phantom/releases/latest)

## Key Features
- **Multi-Core Architecture:** Powered by wgpu/Vulkan, Rayon parallel physics, and optimized memory management.
- **Instant Unpack (AssetArchive VFS):** Reads 15,000+ assets directly from a single assets.tar container in memory.
- **Phantom Launcher (egui):** Lightweight native launcher with Skin Manager, Modrinth catalog, smart mod filtering, and 1-click Crossplay server hosting (Java + Bedrock).
